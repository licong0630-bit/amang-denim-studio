# 阿氓 · Denim Studio

访问网站：https://licong0630-bit.github.io/amang-denim-studio/

此仓库通过 GitHub Pages 从 main 分支根目录部署。网站完全在浏览器运行，上传图案与草稿保存在本机浏览器。

牛仔裤图案样机网站，使用 codex1118 提供的 8 张真实底图，未使用 AI 生成人物。

运行：在项目根目录执行 `python3 -m http.server 4173`，打开 http://localhost:4173。

上传透明背景图案，拖动定位。右侧调整尺寸、旋转、曲面与透视，支持原图明暗、褶皱和布纹融合。每个角度独立编辑；复制到其他角度后需分别校准。可重新圈选裤装区域。

点击“导出当前单张”只导出当前角度。右侧可选择任一角度单独导出；“全部单张打包 ZIP”会生成各自独立的 PNG 文件，解压后每个角度一张。拼图保留独立入口。支持 1000×1500 和 2000×3000 尺寸。

在“角度底图”中，可替换任意预设图片，也可“整套换款 / 批量替换”。整套替换按文件名排序，图库数量以所选文件为准；保留对应顺序的图案，新底图需重新圈定裤装区域。可编辑角度名称，替换操作支持撤销。新款底图不限蓝色牛仔布。

界面主要按钮 14–16px，参数标签 14px，输入数值 16px，两侧面板已加宽。

草稿保存在当前浏览器；保存工程可下载含图片和图层的 JSON 文件，之后从“角度底图”导入。

这是基于二维照片的近似曲面贴图工具，不等同于三维服装仿真、刺绣立体渲染或生产打版。跨缝与复杂遮挡需要手动校准。

已检查 JavaScript 语法、手机与桌面布局、角度切换、复制与撤销、单张选择导出、8 张独立 PNG 生成、ZIP 结构及 CRC 完整性、单图替换、整套换款和撤销后底图恢复。
