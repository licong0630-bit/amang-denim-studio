# 阿氓 · Denim Studio

## 放大查看与自定义刀版

点击任意效果图打开完整合成图的大图预览，可缩放至原始大小或继续放大、拖动查看细节，并通过按钮或左右方向键切换角度。支持滚轮及触控双指缩放、Esc 关闭，也可从大图中导出当前角度。预览读取完整合成画布，不放大缩略图。

四块裤片旁的替换入口，或“管理 / 替换刀版”按钮，可以分别上传单块 SVG、PNG、JPG / WEBP 刀版。图案会保留；上传后需检查闭合轮廓，并调整腰口、臀部、裆部、大腿、膝部和裤脚的六条贴图关键线。可使用识别轮廓或手动网格外缘裁切，支持重新调整范围、恢复默认 M 码及撤销。

这里校准的是贴图坐标，不会修改原生产刀版文件。自定义刀版、识别轮廓、坐标与原始文件保存在浏览器草稿及工程文件中。换款后，涉及这块裤片的照片需重新确认一次对应关系；以后仍可在裤片上设计一次，自动应用到相关照片。

已验证八张图的放大切换、100% 查看、平移、键盘快捷键、当前角度导出、上传 SVG 闭合轮廓识别、自定义刀版刷新恢复、恢复默认时保留图案，以及手机布局。

## M 码刀版工作台

从“刀版设计 · 8 图同步”进入，选择穿着者方向的右前、左前、左后或右后裤片。图案仅保存在共享裤片坐标中，每张照片通过独立的对应网格显示可见部分；不会给每张照片复制一套图案。

可上传图案、拖动定位、调尺寸/旋转/透明度、整片平铺、复制到对称裤片。右侧同时预览 8 张照片，支持单张 PNG 和独立 PNG 的 ZIP 打包。更换底图后，通过“校准对应”保存一次网格，之后改图案会自动更新。

M 码来源于用户提供的水后尺码表，已确认脚口 49.5 cm 为单条裤脚周长，平铺宽 24.75 cm。主裤片由尺寸约束构形；腰头高 4 cm、前后围度分配、裆弧和内缝曲率均为明确记录的假设。原表侧长为直量，本稿拟合侧缝弧长；膝位暂按裆点垂直下 30 cm。未添加生产缝份、缩水放量、省道和门襟。

本功能是二维贴图草稿与照片网格映射，不是可直接生产的裁剪版，也不是三维服装仿真。数值回算符合所选建模口径，不证明成衣平衡与实物合体。

数据和说明位于 `pattern-data.js` 与 `downloads/denim-M-pattern-review.pdf`，可编辑 SVG/JSON 位于下载目录的 ZIP。旧版逐图设计保留，在刀版界面可选择是否叠加。

已验证主尺寸回算、四块裤片的左右方向、前后片可见性、拖动/数字定位、刷新恢复、照片校准、2000×3000 单张导出、8 张独立 PNG 生成，以及手机和桌面无横向溢出。

访问网站：https://licong0630-bit.github.io/amang-denim-studio/

此仓库通过 GitHub Pages 从 main 分支根目录部署。网站完全在浏览器运行，上传图案与草稿保存在本机浏览器。

牛仔裤图案样机网站，使用 codex1118 提供的 8 张真实底图，未使用 AI 生成人物。

运行：在项目根目录执行 `python3 -m http.server 4173`，打开 http://localhost:4173。

上传透明背景图案，拖动定位。右侧调整尺寸、旋转、曲面与透视，支持原图明暗、褶皱和布纹融合。每个角度独立编辑；复制到其他角度后需分别校准。可重新圈选裤装区域。

点击“导出当前单张”只导出当前角度。右侧可选择任一角度单独导出；“全部单张打包 ZIP”会生成各自独立的 PNG 文件，解压后每个角度一张。拼图保留独立入口。支持 1000×1500 和 2000×3000 尺寸。

在“角度底图”中，可替换任意预设图片，也可“整套换款 / 批量替换”。整套替换按文件名排序，图库数量以所选文件为准；保留对应顺序的图案，新底图需重新圈定裤装区域。可编辑角度名称，替换操作支持撤销。新款底图不限蓝色牛仔布。

界面主要按钮 14–16px，参数标签 14px，输入数值 16px，两侧面板已加宽。

草稿保存在当前浏览器；保存工程可下载含图片和图层的 JSON 文件，之后从“角度底图”导入。

这是基于二维照片的近似曲面贴图工具，不等同于三维服装仿真、刺绣立体渲染或生产打版。跨缝与复杂遮挡需要手动校准。
